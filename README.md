# Dynamic Shoots — Photography website

This edition includes **10 optimized photos from your Google Drive folder**, a sports-first homepage, a portrait and event selection, electric-blue branding, and your YouTube sports recap embed.

## Preview
Unzip, then open `index.html` in a browser. Images live in `images/`; keep that folder alongside the HTML file.

## Publish free on GitHub Pages
1. Create a free GitHub account.
2. Create a new public repository named `dynamic-shoots`.
3. Upload the **contents** of the `dynamic-shoots` folder (including the `images` folder), not the ZIP itself.
4. Open Settings → Pages → Build and deployment → Deploy from a branch; choose `main` and `/ (root)`.
5. Wait for GitHub Pages to publish the URL shown there.

## Activate the contact form
1. Create a free form at https://formspree.io/ (check current free-tier limits).
2. Replace `REPLACE_WITH_YOUR_FORM_ID` in `index.html` with the actual Formspree form ID.
3. Test a submission and confirm delivery before sharing the website. Until configured, the form is **not active**.

## Before launch
- Confirm you have permission to publicly display each photo (particularly identifiable minors or client work).
- Add your real Instagram link to the footer.
- Check the YouTube video embed; it can be affected by YouTube privacy, copyright or Shorts playback restrictions.
- Review your About text and service area.
- For faster updates, replace images with files of the same name or edit the gallery in `index.html`.

Hosting costs $0 on GitHub Pages with its free address; a custom domain is optional and paid.
